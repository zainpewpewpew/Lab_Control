ACCESS CONTROL

Web Protection

Tentukan domain yang tidak boleh diakses dari Chrome dan Microsoft Edge.

MANAGED POLICY

Blocked website domains

Masukkan satu domain per baris. Domain utama dan subdomain-nya akan diblokir dalam mode Enforce.

Contoh: example.invalid · jangan masukkan http:// atau path

Enforcement mode

Pilih apakah kebijakan harus langsung memblokir atau hanya mencatat pelanggaran.

Perubahan disinkronkan oleh agent saat polling berikutnya, kemudian browser extension memperbarui aturannya. Browser lain dan aplikasi native belum dijamin terblokir.
DATA LOSS PREVENTION

File Transfer Controls

Batasi file berisiko dan destinasi upload yang tidak disetujui perusahaan.

BROWSER DLP PILOT

Download policy

Ekstensi file yang akan dibatalkan jika dapat terdeteksi saat browser mendownload.

Satu ekstensi per baris, tanpa titik. Windows agent juga memantau folder Downloads.

Upload file policy

Blokir upload file berdasarkan ekstensi.

Restricted upload destinations

Semua file yang dipilih untuk upload melalui form browser ke domain ini ditolak dalam mode Enforce.

Tidak memindai isi dokumen, tidak mencegah semua metode upload kustom, dan tidak menggantikan Microsoft Purview Endpoint DLP.
